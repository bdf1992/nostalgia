# Booth audio source

This folder contains the reviewed process-loopback capture helper, loopback viewer, and per-process CoreAudio status/mute control. Build outputs and local access receipts belong in repository `state/`. Read [BOOTH-AUDIO.md](../../docs/BOOTH-AUDIO.md) for prerequisites, commands, protocol and validation limits.

The [native Booth host](../../docs/NATIVE-GAMEPLAY.md) integrates this package with Nostalgia's CLI and stdio MCP. Its trusted local context supplies the owned inactive desktop and exact target/tool pins to `createBoothAudioRoute`; actual Cable-session admission precedes `startViewer`. Play is explicit, with independent viewer mute and volume. The first real Elden Ring MCP smoke retained 529,200 PCM bytes and 261,510 nonzero samples without owner-speaker playback in the capture test. This finite observation does not establish continuous silence or full baseline admission.

The fifth public-host run retained a combined viewer screenshot of Mary at Belurat, a decoded 2560×1440 `/stream.mjpg` image, and 529,200 PCM bytes with 261,450 nonzero samples. Browser Mute preceded Play; Audio connected while muted and Stop returned Audio stopped. Evidence is under `state/elden-booth-viewer-retry-20261011/`. The first MCP stop returned `native_shutdown_incomplete`; an explicit retry returned `stopped`. Cleanup verified game/controller/viewer closure, the three original empty app render preferences restored, six global defaults unchanged and desktop closure; the public host exited naturally with code 0. Original save bytes remained unchanged and its backup stayed absent. These observations do not establish human audibility, outgoing damage or pickup/inventory baseline admission.

`experimental/` contains reviewed routing source templates. The [routing adapter](ROUTING.md) generates admission headers for one owned Booth and builds fresh local artifacts, preserving exact executable/DLL hashes and inactive-desktop checks. It is separate from `build.ps1` and does not launch normal gameplay. Shutdown quiesces the owned game/controller, closes capture, restores saved app render preferences, then closes Booth. Keep the desktop available through restoration; retain unresolved cleanup failures.
