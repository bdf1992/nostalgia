# Experimental routing preflight

`../route.mjs` compiles these source templates into a fresh repository `state` directory. `SeederAdmission.h` binds the exact executable, output root and Cable render endpoint; `LauncherAdmission.h` additionally binds the executable/DLL digests and one owned inactive Booth desktop. Separate headers avoid circular DLL hash generation. No machine pathname or desktop allowlist is widened in source. No binaries, driver installer, ME3 profile or game content are included.

The private root worker must supply its actual retained Booth receipt and exact target/source/toolchain pins. A public MCP caller's desktop label is not authority. The adapter is being validated against an authored fixture; it does not provide general game launch or save recovery.

`Seeder.cpp` executes outside DllMain, verifies its actual executable against generated admission and configuration, registers only zero PCM, waits for its own single-process CoreAudio session, records the three original render preferences exclusively, and sets the exact admitted Cable endpoint. It checks readback, closes its stream and exits its own preflight process. Failure rolls back every successfully changed role in reverse order to its in-memory prior value. Restore uses the retained original snapshot and refuses any current preference other than Cable or that original. The controller attempts snapshot-backed restore after every seed error, including transport or receipt failures.

`SuspendedPreflight.cpp` creates a new exact pinned executable with CREATE_SUSPENDED on the exact existing inactive desktop. It holds executable/DLL files, refuses reparse ancestors, assigns a private non-inherited kill-on-job-close job before bootstrap, and never resumes the primary thread. The exact x64 return-zero bootstrap uses temporary RW then RX memory; remote LoadLibraryW and the initializer use verified remote module bases plus export RVAs. Waits are bounded. Failure terminates only its newly-created held child; helper death closes its private job. It neither launches normal gameplay nor terminates an existing game.

Ordinary imported DLL initialization and TLS callbacks can run during bootstrap. A suspended primary thread proves Main was not resumed; it does not prove arbitrary game TLS silence. ME3 native-load failure alone does not guarantee stopped Main. The private AudioPolicyConfig ABI is version-dependent and unsupported by Microsoft; observed success on this local Windows build is not portability evidence.

Keep the owned inactive Booth desktop alive until normal gameplay is quiescent and routing restoration completes, then finalize Booth. Lease expiry does not suppress restoration, but a removed desktop makes the exact admitted helper refuse; retain that unresolved failure. The controller records all six device-default roles before and after, and never changes them. The current adapter provides app preference routing evidence, not proof that a fresh game actually selected the cable; root must observe that game session before admitting viewer playback.
