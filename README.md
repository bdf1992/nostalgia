# Nostalgia

A small, agent-assisted compatibility and multiplayer helper for playing classic games you legally possess.

Nostalgia does **not** distribute commercial game images, proprietary BIOS/firmware, encryption keys, or other copyrighted console data. It provides recipes, emulator/runtime metadata, multiplayer setup guidance, diagnostics, and safe local state management.

This repository is being bootstrapped as a quick-and-dirty v0.1 experiment.
